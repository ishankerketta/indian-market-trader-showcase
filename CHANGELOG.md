# Changelog

Public release notes for Indian Market Trader. This file covers user-facing changes only.

## 2026-11-10: Initial public showcase

- Published this showcase repository, with the product overview, real sample screenshots, documentation and an illustrative trade walkthrough.
- It describes the current **beta (v0.3.x)**: 15 skills covering market pulse, scanner, levels, news, sentiment, deals, entry, exit, Time Machine odds, charges, position sizing, risk checks, broker orders (paper by default), alerts and a journal.
- Verified so far: market pulse, the daily and opening-range scans, entry check, exit plan and Time Machine, run live on a Mac. Angel One and Dhan login and read-only checks work on real accounts.
- Not yet tested: placing real orders, the other brokers, and Windows.
