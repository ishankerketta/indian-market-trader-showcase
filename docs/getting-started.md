# Getting started

The official version of Indian Market Trader is available **only** through its Agensi listing. This showcase repository does not contain the product and cannot be installed.

## 1. Get the official version

Go to the Agensi listing and complete your purchase there:

**→ [Indian Market Trader on Agensi](https://www.agensi.io/skills/indian-market-trader)**

After you buy, follow the installation instructions that come with your purchase. They are the supported way to install the skills.

## 2. Before you install, check you have

- **A computer you can run Claude on.** The skills run on your own computer, through **Claude Code** or the **Code tab of the Claude desktop app**. Checked on a Mac. Windows has not been tested yet.
- **A paid Claude plan** if you use Claude Code.
- **Python 3** installed on that computer.
- **Internet access** to public market-data sites (Yahoo Finance, NSE, Google News and Reddit).

Claude's cloud chat (claude.ai or the Chat tab of the desktop app) blocks the market-data sites by default, so the skills are not recommended there.

## 3. Ask your first question

Once it is installed, start a session in Claude Code or the desktop app's Code tab and type in plain words:

- "How's the market looking today?"
- "Make my watchlist for tomorrow"
- "Show me the levels for TCS"
- "Plan a trade in RELIANCE with ₹500 maximum loss"

The first time you plan a trade, Claude asks for your capital, your loss limits and your broker, and saves them. Everything starts in **paper trading** (pretend money).

## 4. Connecting a broker (optional)

Connecting a broker is optional. You log in yourself in a terminal prompt, so your password, PIN and API secret are never typed into the chat. Broker sessions usually expire each trading day, so you log in again each day. See [Privacy and security](privacy-and-security.md) and the [compatibility table](../README.md#requirements-and-compatibility) for which brokers have been tested.
